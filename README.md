# pairwise-audio-channel-order

5.1 素材在耳机上听，人声跑到后脑，内部声道顺序按 L R C LFE Ls Rs 存，设备却按 L R Ls Rs C LFE 解释；下混系数把中置当成了环绕，人声被送到后方；LFE 直接混进左右声道，低频把耳机推得失真；左右环绕反相时下混没有检测，人声被抵消失；单声道素材被当成双声道，两个声道各出一半；声道数按容器头判断而不是按实际数据，缺声道时读越界；重采样器按交错采样处理，多声道下指针错位；输出设备只支持立体声，却没有做布局协商；上混时把环绕复制到前置，声场被拉扁；声道布局元数据在转码后丢失，下游只能猜。media/audio_channel_order.py 是核心，tests/test_audio_channel_order.py 15个红。要修的是：显式声道映射；标准下混系数；LFE 低通；相位检测；单声道复制；按实际声道数；按帧重采样；设备布局协商；正确上混；保留布局元数据。

## 运行

```bash
python -m pytest tests -q
```
